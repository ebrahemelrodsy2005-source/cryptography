Overview

Rail Fence Cipher is a classical transposition cipher that does not change the letters themselves, but rearranges their positions in a zigzag pattern across multiple "rails".

It is called a rail fence because the writing pattern looks like a zigzag fence. The security depends on hiding the arrangement order, not the characters.

Algorithm 

🔐 ENCRYPTION STEPS:

1. Choose number of rails (key = 3 in our example)
2. Write the plaintext in zigzag form:
   move down the rails then up repeatedly
3. Fill characters row by row in a zigzag pattern
4. Read each row from top to bottom
5. Combine rows → Ciphertext

🔓 DECRYPTION STEPS:

1. Create empty zigzag structure based on text length
2. Mark rail pattern (same zigzag path)
3. Fill ciphertext row by row into marked positions
4. Read zigzag path again to recover original text

🔐 Worked Example (Encryption)

Plaintext: HELLOWORLD
Key (Rails): 3

Step 1: Write in zigzag pattern

Rail 1: H     O     L
Rail 2:  E   L W   R D
Rail 3:   L O     O

Step 2: Read row by row
Rail 1 → HOL
Rail 2 → ELWRD
Rail 3 → LOO
Ciphertext: HOLELWRDLO

🔓 Worked Example (Decryption)

Ciphertext: HOLELWRDLO
Key (Rails): 3

Step 1: Determine zigzag pattern size

Step 2: Fill rows based on rail counts

Rail 1: H   O   L
Rail 2:  E L W R D
Rail 3:   L O   O

Step 3: Read zigzag path

Recovered Text: HELLOWORLD
