Overview

Stream Cipher encrypts data one character (or bit) at a time using XOR. It is fast and used in real-time encryption systems.

Algorithm

Encryption Process: 1. Convert each character → ASCII value 2. Convert ASCII → Binary (8-bit) 3. Apply XOR between plaintext binary and key binary 4. Repeat key if needed 5. Convert result back to binary ciphertext Decryption Process: 1. Take binary ciphertext 2. Apply XOR between ciphertext binary and key binary 3. Binary (8-bit) → Convert ASCII 4. Convert ASCII value → character Formula: C = (P ⊕ K) P = (C ⊕ K)

Encrypt Example

Plaintext: H Key: K Step 1: ASCII H = 72 → 01001000 K = 75 → 01001011 Step 2: XOR 01001000 ⊕ 01001011 = 00000011 Step 3: Binary Output Ciphertext = 00000011

🔓 Decrypt Example

Ciphertext: 00000011 Key: K Step 1: Binary → ASCII K = 75 → 01001011 c= 00000011 Step 2: XOR with Key 00000011 ⊕ 01001011 = 01001000 Step 3: binary → ASCII 01001000 =72 step4: Convert ASCII value → character 72 → H Recovered Text = H
