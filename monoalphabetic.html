Overview

Monoalphabetic Cipher is a substitution cipher where each letter in the plaintext is replaced with a fixed corresponding letter from a shuffled alphabet. It is a 1-to-1 mapping (bijection).

Algorithm

E(P) = substitution_table[P]
D(C) = inverse_table[C]

Where:
- P = plaintext letter
- C = ciphertext letter
- Each letter has a unique mapping

🔐 Worked Example (Encryption)

Plaintext: HELLO WORLD

Substitution:
H → W
E → P
L → Y

(space)
