Overview

AES is a symmetric encryption algorithm that works on 128-bit blocks. It uses multiple rounds of substitution, shifting, mixing, and XOR operations.

Algorithm

1. Text → ASCII → Hex
2. Arrange into 4×4 Matrix
3. AddRoundKey (XOR)

Repeat:
- SubBytes (S-Box)
- ShiftRows
- MixColumns
- AddRoundKey

Final Round:
- SubBytes
- ShiftRows
- AddRoundKey

🔐 Worked Example (Encryption)

1. Text → ASCII → Hex
2. Arrange into Matrix (State)

3. AddRoundKey (XOR)

4. Repeat:
   - SubBytes (S-Box)
   - ShiftRows
   - MixColumns
   - AddRoundKey
5. Final Round (MixColumns)
6. Matrix → Hex → Ciphertext

Plaintext: HELLO
→ Hex: 48 45 4C 4C 4F

Encryption:
AES(key, IV, data)
Output:
Random Base64 (changes every time)

🔓 Worked Example (Decryption)

Ciphertext (hex):
b9847e2c2476...

Password: mySecret

Step 1 → Decode Base64 → bytes  
Step 2 → Extract IV (first 12 bytes)  
Step 3 → Extract Cipher data  
Step 4 → Generate key using PBKDF2  
Step 5 → AES Decrypt using same key + IV  

Result:
Plaintext: HELLO
