Overview

Vigenère Cipher is a polyalphabetic cipher that uses a keyword to apply multiple Caesar shifts. Each letter in the plaintext is shifted based on the corresponding letter in the keyword.

Algorithm

E(i) = (P(i) + K(i mod keylen)) mod 26
D(i) = (C(i) - K(i mod keylen)) mod 26

Where:
P = plaintext letter position
C = ciphertext letter position
K = keyword letter shift

🔐 Worked Example (Encryption)

Plaintext: HELLO WORLD
Keyword: KEY

Step 1: Repeat keyword
KEYKEYKEYKE

Step 2: Convert letters
K=10, E=4, Y=24

Step 3: Encryption
H + K(10) → R
E + E(4)  → I
L + Y(24) → J
L + K(10) → V
O + E(4)  → S
(space stays)
W + Y(24) → U
O + K(10) → Y
R + E(4)  → V
L + Y(24) → J
D + K(10) → N

Step 4: Result
Ciphertext: RIJVS UYVJN

🔓 Worked Example (Decryption)

Ciphertext: RIJVS UYVJN
Keyword: KEY

Step 1: Repeat keyword
KEYKEYKEYKE

Step 2: Decryption
R - K(10) → H
I - E(4)  → E
J - Y(24) → L
V - K(10) → L
S - E(4)  → O
(space stays)
U - Y(24) → W
Y - K(10) → O
V - E(4)  → R
J - Y(24) → L
N - K(10) → D

Step 3: Result
Plaintext: HELLO WORLD
