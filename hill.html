Overview

Hill Cipher is a polygraphic substitution cipher that encrypts letters in groups (vectors) using matrix multiplication under modulo 26 arithmetic.

Algorithm

Encryption:
C = K × P (mod 26)

Decryption:
P = K⁻¹ × C (mod 26)

Where:
K = key matrix
P = plaintext vector
C = ciphertext vector

Step 3: Multiply by matrix (mod 26)

[3 3]   [7,8]   → (3×7 + 3×8) = 45 → 19 = T
[2 5]           → (2×7 + 5×8) = 54 → 2  = C
