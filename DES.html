Overview

DES (Data Encryption Standard) is a symmetric block cipher that works on 64-bit blocks using Feistel structure and 16 rounds of processing.

Algorithm

1. Plaintext → 64-bit block
2. Initial Permutation (IP)
3. Split into L0 and R0

For 16 rounds:
- Expand R
- XOR with Round Key
- Substitution (S-Boxes)
- Permutation
- Swap L and R

Final:
- Combine L16 + R16
- Final Permutation (FP)

🔐 Worked Example (Encryption)

Plaintext: HELLO123

Step 1 → Convert to 64-bit block  
Step 2 → Initial Permutation  
Step 3 → Split L and R  

Repeat 16 rounds:
- Expansion
- XOR Key
- S-Box
- Permutation
- Swap

Output:
Ciphertext (HEX)

🔓 Worked Example (Decryption)

Ciphertext (HEX):
8a3f91c7...

Key: mySecretKey

Step 1 → Convert HEX to bits  
Step 2 → Apply Initial Permutation  
Step 3 → Run 16 rounds in reverse keys  
Step 4 → Final Permutation  

Result:
Plaintext: HELLO123
