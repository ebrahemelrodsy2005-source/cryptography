Overview

One-Time Pad (OTP) is a perfect encryption technique where each character is encrypted using a completely random key that is as long as the message itself and used only once.

⚠️ Real OTP requires truly random physical keys — software-based versions are for learning only.

Algorithm

Encryption:
E(i) = (P(i) + K(i)) mod 26

Decryption:
D(i) = (C(i) - K(i)) mod 26

Rules:
- Key length = message length
- Key is random
- Key used only once

🔐 Worked Example (Encryption)

Plaintext: HELLO
Key:       XJRKY

Step 1: Convert to numbers
H=7 E=4 L=11 L=11 O=14
X=23 J=9 R=17 K=10 Y=24

Step 2: Apply OTP formula
( P + K ) mod 26

H → (7 + 23) = 30 → 4  → E
E → (4 + 9)  = 13 → N
L → (11 +17) = 28 → 2  → C
L → (11+10)  = 21 → V
O → (14+24)  = 38 → 12 → M

Step 3: Result
Ciphertext: ENCVM

🔓 Worked Example (Decryption)

Ciphertext: ENCVM
Key:       XJRKY

Step 1: Convert to numbers

E=4 N=13 C=2 V=21 M=12
X=23 J=9  R=17 K=10 Y=24

Step 2: Apply formula
(P = C - K) mod 26

E → (4 - 23) = 7  → H
N → (13-9)   = 4  → E
C → (2 -17)  = 11 → L
V → (21-10)  = 11 → L
M → (12-24)  = 14 → O

Step 3: Result
Plaintext: HELLO
