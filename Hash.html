Overview

SHA-256 Hash is a cryptographic hash function that converts any input into a fixed 256-bit output. It is irreversible and used in security systems.

Algorithm

1. Input Message
2. Padding
3. Split into 512-bit blocks
4. Compression Function
5. 64 Rounds Processing
6. Output → 256-bit Hash

Example

Input: hello

Output:
SHA-256 =
