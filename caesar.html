Overview

Caesar Cipher is a substitution cipher where each letter in the plaintext is shifted by a fixed number (key) in the alphabet. Spaces are preserved and all letters wrap around using mod 26.

Algorithm

Encryption:
E(x) = (x + k) mod 26

Decryption:
D(x) = (x - k) mod 26

Where:
x = letter position (A=0 ... Z=25)
k = shift key

🔐 Worked Example (Encryption)

Plaintext: HELLO WORLD
Key: 3

Step 1: Convert letters to numbers
H=7, E=4, L=11, L=11, O=14
W=22, O=14, R=17, L=11, D=3

Step 2: Apply shift (+3)
H → K
E → H
L → O
L → O
O → R
(space stays)
W → Z
O → R
R → U
L → O
D → G

Step 3: Result
Ciphertext: KHOOR ZRUOG

Ciphertext: KHOOR ZRUOG
Key: 3

Step 1: Convert letters to numbers
K=10, H=7, O=14, O=14, R=17

Step 2: Apply shift (-3)
K → H
H → E
O → L
O → L
R → O
(space stays)
Z → W
R → O
U → R
O → L
G → D

Step 3: Result
Plaintext: HELLO WORLD
