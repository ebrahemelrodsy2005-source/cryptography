Overview

RSA is an asymmetric encryption algorithm that uses two keys: a public key for encryption and a private key for decryption.

Algorithm

1. Choose two primes: p, q
2. Compute n = p × q
3. Compute φ(n) = (p-1)(q-1)
4. Choose e such that gcd(e, φ) = 1
5. Compute d such that:
   d × e ≡ 1 mod φ(n)

Public Key = (e, n)
Private Key = (d, n)

Encryption:
C = M^e mod n

Decryption:
M = C^d mod n

🔐 Worked Example (Encryption)

Step 1: Choose primes
p = 3, q = 11

Step 2: Compute n
n = 3 × 11 = 33

Step 3: Compute φ(n)
φ = (3-1)(11-1) = 2 × 10 = 20

Step 4: Choose e
e = 3  (coprime with 20)

Step 5: Compute d
d = 7 (because 3×7 = 21 ≡ 1 mod 20)

Public Key = (3, 33)

Step 6: Encrypt message
M = 4

C = 4^3 mod 33
C = 64 mod 33 = 31

Ciphertext = 31

🔓 Worked Example (Decryption)

Ciphertext: 31
Private Key: d = 7

M = 31^7 mod 33

Result:
M = 4
