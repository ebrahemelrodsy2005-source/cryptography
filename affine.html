Overview

Affine Cipher is a substitution cipher based on a mathematical linear function. It is stronger than Caesar because it uses two keys instead of one.

Algorithm

Encryption:
E(x) = (a × x + b) mod 26

Decryption:
D(y) = a⁻¹ × (y - b) mod 26

Where:
x = letter position (A=0 ... Z=25)
a = key (must be coprime with 26)
b = shift value

L → 63 → 11 → L

🔓 Worked Example (Decryption)

Ciphertext: RCLLA OAPLX
a = 5, b = 8

Step 1: Find modular inverse of a
5⁻¹ mod 26 = 21

Step 2: Convert letters to numbers

O=14 A=0 P=15 L=11 X=23
