Overview

Diffie-Hellman is a key exchange algorithm that allows two parties to generate a shared secret over an insecure channel. It does not encrypt messages directly but creates a secret key used later for encryption.

Algorithm

1. Choose public values:
   - Prime number p
   - Generator g

2. Hema chooses secret a
   Abdo chooses secret b

3. Compute:
   A = g^a mod p
   B = g^b mod p

4. Exchange A and B

5. Compute shared key:
   Hema: K = B^a mod p
   Abdo:   K = A^b mod p

🔐 Worked Example

Given:
p = 23, g = 5

Hema:
a = 6
A = 5^6 mod 23 = 8

Abdo:
b = 15
B = 5^15 mod 23 = 19

Exchange:
Hema receives 19
Abdo receives 8

Compute key:

Hema:
K = 19^6 mod 23 = 2

Abdo:
K = 8^15 mod 23 = 2

✔ Shared Key = 2
